# ISO 27001 + SOC 2 + AI Governance — Progress Tracker

Interactive 10-week learning plan tracker: ISO/IEC 27001:2022 Foundation, SOC 2, and GRC + AI Governance.

Open `index.html` in a browser, or enable GitHub Pages on this repo for a live link. Progress (checkboxes) is saved locally in the browser via `localStorage` — nothing is sent to a server.

## Structure

- `index.html` — the tracker UI (single page, no build step, no dependencies)
- `data.js` — the learning plan content (weeks, tasks, links, checklists), parsed from the original plan

## Content

- **Phase 1 (weeks 1–4):** ISO/IEC 27001:2022 Foundation — clauses 4–10, Annex A, practice exams
- **Phase 2 (weeks 5–7):** SOC 2 — Trust Service Criteria, Common Criteria, evidence collection, access controls
- **Phase 3 (weeks 8–10):** GRC + AI Governance — NIST CSF, EU AI Act, ISO 42001, NIST AI RMF

## Deploying

To publish as a live site: Settings → Pages → Deploy from branch → `main` / `root`.
